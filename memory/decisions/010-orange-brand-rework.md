# The brand is orange on cream, with the pot-and-m mark

Decision: on 2026-08-19 the owner replaced the original forest-green palette with a new brand: cream paper (#faf4e6 light, warm near-black dark), brand orange primary (#e0761a light, #f19a44 dark), an orange pot logo with a lowercase m knockout and liquid blobs, Fraunces for display headlines, Baloo 2 for the lowercase "meltingpot" wordmark, and pill-shaped buttons. The landing hero matches the owner's supplied mock: nav with Home, Spaces, Explore, Sign in, and a dark Get started pill; the headline "Many ideas. One shared knowledge base."; an orange Get started pill with a Learn more link; and the large pot illustration bleeding off the hero's bottom edge.

This supersedes the SPEC's palette pins on that axis (owner directive wins). Two SPEC rules were preserved deliberately: the no-login-wall promise (code entry moved from the hero to the #spaces section one anchor below, where the nav and hero CTAs land) and functional color with text labels. The "no gradients" rule now has exactly one sanctioned exception: the gradient inside the brand mark SVGs (components/brand/pot-mark.tsx, app/icon.svg), because the owner's icon uses one. Everything else stays flat and token-driven.

Implementation notes: all colors flow from the token block in web/app/globals.css, so the palette swap recolored the whole app; the mark is hand-drawn SVG (crisp at favicon size, no binary assets in the repo); favicon.ico and apple-icon.png are rasterized from app/icon.svg. The supplied mock's body copy said "teams" and used an em dash; the shipped copy says "classes" and drops the dash per the product's copy rules.

Accepted trade, on the record: small orange link text on cream sits near 3.1:1, under the 4.5:1 AA number, because the owner's palette directive picks the mock's bright orange. Fills, large text, and the dark theme (where the orange is lighter on near-black and passes comfortably) are unaffected; light-theme faint text was darkened to hold AA on the lighter cream.
