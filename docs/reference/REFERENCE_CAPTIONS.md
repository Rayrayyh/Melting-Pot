# MeltingPot Reference Image Captions

Attach the images in numerical order. These screenshots are UX and information-architecture references, not final visual-design references. Build the product as a responsive desktop web app using the warm paper, forest-green, and clay direction from the master prompt. Adapt the narrow contribution screens into desktop layouts with persistent navigation, wider content areas, contextual side panels, and side-by-side comparisons where appropriate.

## Image 1: Onboarding and account-status flow

**File:** `01-onboarding-flow.png`

Use this image for the class-code-first sequence and the account-status branching: enter a code, validate it, show the Pot before authentication, then either open it for an existing member, sign in an existing account, or create a new account. Ignore the purple and blue styling, mobile card dimensions, school-confirmation language, flashcards, practice cards, and any organization-related copy. The final product must not ask for school initials or school verification.

## Global interpretation rule

When an image conflicts with the written master prompt, follow the written master prompt. Use the images to understand hierarchy, sequence, layout relationships, and interaction boundaries. Do not copy outdated features, school or organization concepts, mobile dimensions, or the old blue, yellow, and purple styling.
